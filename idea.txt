🩺 Sistema de gestión de turnos

Es una API REST para gestionar turnos entre profesionales y clientes.

El flujo principal sería:

Profesionales
Crear profesionales.
Definir especialidad.
Definir duración predeterminada de los turnos.
Definir sus horarios de atención.

Clientes
Registrar clientes.
Guardar nombre, email y teléfono.
Buscar clientes por ID.

Turnos
Un cliente solicita un turno con un profesional.
El sistema verifica:
Que exista el profesional.
Que exista el cliente.
Que el horario esté dentro del horario laboral.
Que no haya otro turno ocupado en ese horario.
Si todo está bien, crea el turno como pending.

Estado del turno

pending → turno solicitado.
confirmed → turno confirmado.
canceled → turno cancelado.

Notificaciones
Cuando se crea/confirmar un turno, el servicio se encarga de enviar una notificación.
